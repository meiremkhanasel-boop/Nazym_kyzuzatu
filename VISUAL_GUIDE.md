## 💡 ПОДСКАЗКИ И СОВЕТЫ

### Совет 1: Загрузка Своего Фото
```
1. Нажми "📸 Фото таңдаңыз"
2. Выбери JPEG файл со своего компьютера
3. Фото загружается в рамку
4. Оно сохраняется в браузере даже после перезагрузки
```

### Совет 2: Быстрая Проверка Таймера
```
1. Откройте приложение
2. Посмотрите на таймер (должны быть большие числа)
3. Подождите 5 секунд
4. Числа должны измениться
```

### Совет 3: Проверка Мобильности
```
1. В браузере: F12
2. Нажми Ctrl+Shift+M
3. Выбери iPhone или Android
4. Проверь что всё красиво выглядит
```

### Совет 4: Экспорт в Excel
```
1. Собрал все RSVP ответы
2. В Console выполнил команду выше
3. Данные скопировались в буфер обмена
4. Открыл Excel
5. Вставил (Ctrl+V)
6. Готово! Данные в таблице
```
