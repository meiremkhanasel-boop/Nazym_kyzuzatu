2️⃣ УСТАНОВКА SQL SERVER:
─────────────────────────────────────────────────────────────────────────────

Вариант A: SQL Server Express (бесплатно)
─────────────────────────────────────────

1. Скачайте: https://www.microsoft.com/ru-ru/sql-server/sql-server-downloads
2. Выберите "Express" (бесплатная версия)
3. Установите с дефолтными параметрами
4. Укажите пароль для SA (администратор): YourPassword123
5. Включите TCP/IP протокол:
   • SQL Server Configuration Manager
   • SQL Server Network Configuration
   • Protocols for SQLEXPRESS
   • TCP/IP -> Enabled

Вариант B: Docker (если уже установлен Docker)
────────────────────────────────────────────

Откройте PowerShell и выполните:

docker run -e "ACCEPT_EULA=Y" -e "SA_PASSWORD=YourPassword123" `
  -p 1433:1433 `
  -d mcr.microsoft.com/mssql/server:2022-latest

3️⃣ СОЗДАНИЕ БАЗЫ ДАННЫХ:
─────────────────────────────────────────────────────────────────────────────

Способ 1: Через SQL Server Management Studio (SSMS)
───────────────────────────────────────────────────

1. Откройте SSMS
2. Подключитесь к: localhost\SQLEXPRESS (или просто localhost:1433)
3. Логин: sa
4. Пароль: YourPassword123
5. Откройте файл: CREATE_DATABASE.sql
6. Нажмите: Execute (Ctrl+E)
7. ✅ База данных создана!

Способ 2: Через PowerShell
───────────────────────────

Откройте PowerShell и выполните:

# Установите модуль sqlserver если нет
Install-Module -Name SqlServer -Force -Confirm:$false

# Выполните SQL скрипт
$script = Get-Content "D:\ITPROGRAM\intelidea\Nazym_kyzuzatu\CREATE_DATABASE.sql" -Raw
Invoke-Sqlcmd -ServerInstance "localhost\SQLEXPRESS" `
  -Username "sa" `
  -Password "YourPassword123" `
  -Query $script

─────────────────────────────────────────────────────────────────────────────

Обновите класс DatabaseConnection:

Файл: src/main/java/com/assel/nazym_kyzuzatu/DatabaseConnection.java

Параметры подключения (строки 8-11):

    private static final String SERVER = "localhost";        // Хост

7️⃣ РЕШЕНИЕ ПРОБЛЕМ:
─────────────────────────────────────────────────────────────────────────────

❌ ПРОБЛЕМА: "Connection refused"
РЕШЕНИЕ:
   1. Проверьте, что SQL Server запущен
   2. Проверьте порт: netstat -an | findstr 1433
   3. Перезагрузите сервис SQL Server
   4. Проверьте пароль в DatabaseConnection.java

❌ ПРОБЛЕМА: "Login failed for user 'sa'"
РЕШЕНИЕ:
   1. Откройте SSMS
   2. Подключитесь с пароль администратора
   3. Убедитесь, что пароль совпадает в DatabaseConnection.java

❌ ПРОБЛЕМА: "Cannot find database"
РЕШЕНИЕ:
   1. Откройте CREATE_DATABASE.sql
   2. Выполните полный скрипт ещё раз
   3. Проверьте в SSMS, что БД создана

❌ ПРОБЛЕМА: "Driver not found"
РЕШЕНИЕ:
   1. Maven должен скачать драйвер автоматически
   2. Если нет: mvn clean install
   3. Перезагрузите проект
