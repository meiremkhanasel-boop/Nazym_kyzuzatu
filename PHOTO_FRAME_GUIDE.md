## 🔍 ТЕХНИЧЕСКИЕ ДЕТАЛИ

### Обновленный CSS:

```css
.photo-frame img {
    position: absolute;
    inset: 18px;                    /* Отступ от края (размер рамки) */
    width: calc(100% - 36px);       /* Ширина минус рамка */
    height: calc(100% - 36px);      /* Высота минус рамка */
    object-fit: cover;              /* Масштабирование фото */
    display: block;                 /* Всегда видимо */
    z-index: 1;                     /* Под рамкой */
    border-radius: 4px;             /* Скругление углов */
}
```

## 🎨 СПОСОБЫ УЛУЧШЕНИЯ

### Если фото не загружается:

**Проблема:** Рамка пустая, видно только эмодзи 👰

**Решение 1:**
- Проверьте что файл `bg_image.jpeg` находится в `src/main/webapp/`
- Убедитесь что это JPEG формат
- Проверьте имя файла (без пробелов, правильное написание)

**Решение 2:**
- Откройте Developer Tools (F12)
- Перейдите на вкладку "Network"
- Перезагрузите страницу
- Посмотрите загружается ли файл bg_image.jpeg
- Если красный 404 → файл не найден, проверьте путь

**Решение 3:**
- Нажмите кнопку "📸 Өзгеше фото таңдаңыз"
- Загрузите фото через браузер
- Это точно сработает!

---

### Если фото загружено но выглядит странно:

**Проблема:** Фото растянуто, обрезано или не по центру

**Это нормально!** Используется `object-fit: cover` что означает:
- Фото масштабируется чтобы заполнить рамку
- Может быть обрезано если соотношение сторон не совпадает

**Как исправить:**
1. Отредактируйте фото в Paint/Photoshop
2. Измените размер на 3:4 (например, 300x400 px)
3. Замените файл `bg_image.jpeg`
4. Готово! Фото будет выглядеть идеально ✅

## 📞 ПОДДЕРЖКА

### Часто задаваемые вопросы:

**Q: Почему фото не загружается?**
A: Проверьте что файл `bg_image.jpeg` находится в `src/main/webapp/` папке

**Q: Можно ли использовать PNG вместо JPEG?**
A: Да! Просто измените расширение или переконвертируйте формат

**Q: Как сделать чтобы фото не обрезалось?**
A: Отредактируйте фото чтобы оно было 3:4 (например, 300x400 px)

**Q: Можно ли изменить размер рамки?**
A: Да! В CSS найдите `.photo-frame` и измените `max-width: 380px`

**Q: Как убрать эффект мерцания золота?**
A: В CSS найдите `animation: glowPulse` и удалите эту строку
