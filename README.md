# 📚 ПОЛНЫЙ СПРАВОЧНИК ПРИЛОЖЕНИЯ "Қыз ұзату"

## 🎯 Что такое это приложение?

Это **премиум веб-приложение для приглашения на казахский свадебный обряд "Қыз ұзату"** (отправка невесты). 

Приложение включает:
- ✨ Красивый, торжественный дизайн с анимацией
- 📱 Полная адаптивность для мобильных телефонов
- ⏱️ Таймер обратного отсчета до события
- 📋 Форму для подтверждения участия гостей (RSVP)
- 🗺️ Встроенную карту с адресом мероприятия
- 💾 Сохранение данных в браузере

## 💾 Как Работают Данные

### Где Хранятся Данные RSVP?

Все ответы гостей сохраняются **в браузере** в формате JSON в `localStorage`:

```javascript
{
  "name": "Айсулу Абдуллина",
  "count": "2",
  "spouse": "Иә",
  "attending": "Келемін",
  "timestamp": "20.04.2026 14:30:45"
}
```

### Как Просмотреть Данные?

**Шаг 1:** Откройте приложение в браузере

**Шаг 2:** Нажмите **F12** (открыть Developer Tools)

**Шаг 3:** Перейдите на вкладку **"Console"**

**Шаг 4:** Скопируйте эту команду:
```javascript
console.log(JSON.parse(localStorage.invitationRSVPs))
```

**Шаг 5:** Нажмите Enter

**Результат:**
```json
[
  {
    "name": "Айсулу Абдуллина",
    "count": "2",
    "spouse": "Иә",
    "attending": "Келемін",
    "timestamp": "20.04.2026 14:30:45"
  },
  {
    "name": "Жасмин Қасымова",
    "count": "1",
    "spouse": "Жоқ",
    "attending": "Келемін",
    "timestamp": "20.04.2026 15:45:22"
  }
]
```

### Экспорт в Excel или Google Sheets

1. Скопируйте результат из консоли
2. Откройте Excel или Google Sheets
3. Вставьте данные
4. Готово! Данные автоматически распределятся по колонкам

Найдите в файле `index.html` строку:
```javascript
const targetDate = new Date('2026-06-19T18:00:00').getTime();
```

Замените на вашу дату:
```javascript
const targetDate = new Date('2025-12-25T15:30:00').getTime();
// Формат: YYYY-MM-DDTHH:MM:SS
```

## ❓ Часто Задаваемые Вопросы

### Q: Почему фото не загружается при открытии?
**A:** 
- Убедитесь, что файл `photo6.jpeg` находится в `src/main/webapp/`
- Проверьте, что это действительно JPEG формат
- Используйте кнопку загрузки для загрузки другого фото

### Q: Как отправить ответы RSVP администратору?
**A:**
1. Откройте Developer Tools (F12)
2. Выполните команду в консоли:
   ```javascript
   copy(JSON.stringify(JSON.parse(localStorage.invitationRSVPs)))
   ```
3. Данные скопируются в буфер обмена
4. Отправьте администратору в Telegram/WhatsApp или вставьте в Excel

### Q: Можно ли отправить форму на сервер?
**A:** 
Да! Это требует небольшого JavaScript кода. Обратитесь к файлу `EXTENSIONS.md` для примера интеграции с backend API.

### Q: Работает ли без интернета?
**A:** 
Почти да. Карта Google Maps потребует интернет. Остальное работает офлайн.

### Q: Как удалить загруженное фото?
**A:**
```javascript
// В консоли браузера введите:
localStorage.removeItem('invitationCustomPhoto');
location.reload(); // Перезагрузить страницу
```

### Q: Почему анимации не работают?
**A:**
- Проверьте, что AOS библиотека загружена (посмотрите в Network в DevTools)
- Обновите страницу (Ctrl+R)
- Попробуйте другой браузер
