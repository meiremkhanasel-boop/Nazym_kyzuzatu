# 🎬 ВИДЕОИНСТРУКЦИЯ (ТЕКСТОВАЯ): КАК ЗАГРУЖАЕТСЯ ФОТО

## 📹 СЦЕНАРИЙ 1: АВТОМАТИЧЕСКАЯ ЗАГРУЗКА (ЧТО ПРОИСХОДИТ)

### ШАГ 1: Вы открываете index.html в браузере

```
Браузер загружает index.html
         ↓
HTML парсит структуру
         ↓
CSS применяет стили
         ↓
JavaScript запускается
```

### ШАГ 2: JavaScript проверяет наличие фото

```
JavaScript код начинает выполняться:

const photoFile = './bg_image.jpeg';  ← Ищет этот файл
const frameEl = document.getElementById('photoFrame');  ← Находит рамку
const imgEl = document.getElementById('profilePhoto');  ← Находит тег img
```

### ШАГ 3: Попытка загрузить bg_image.jpeg

```
Создается новый Image объект:
    const testImg = new Image();
    testImg.src = './bg_image.jpeg';  ← Пытается загрузить
    
    ↙️ ДА                ↘️ НЕТ
 Файл найден!        Файл не найден!
    ↓                    ↓
Загружает в рамку   Пытается photo6.jpeg
    ↓                    ↓
frameEl.classList    Если найдена
.add('has-photo');   → загружает
    ↓                    ↓
Эмодзи 👰         frameEl.classList
исчезает           .add('has-photo');
    ↓
imgEl.src = photoFile;
```

    imgEl.src = dataUrl;          ← Загружает в img

### ШАГ 6: Фото сохраняется в браузер

```
JavaScript код:

try {
    localStorage.setItem(
        'invitationCustomPhoto',  ← Ключ в браузере
        dataUrl                    ← Данные фото
    );
} catch (e) { }
```

**Что это означает?**
- Фото сохраняется на вашем компьютере (в браузере)
- При следующем открытии страницы → фото загружается автоматически
- Это работает пока вы не очистите кэш браузера

## 📹 СЦЕНАРИЙ 3: ПРИОРИТЕТ ЗАГРУЗКИ

```
Приложение проверяет в таком порядке:

1️⃣ ПЕРВЫЙ ПРИОРИТЕТ:
   └─ localStorage.invitationCustomPhoto
      (Фото которое ВЫ загрузили в браузер)
      
   Если найдено → ЗАГРУЖАЕТ ✅
   Если НЕ найдено → переходит к 2️⃣

2️⃣ ВТОРОЙ ПРИОРИТЕТ:
   └─ ./bg_image.jpeg
      (Фото сестры в папке src/main/webapp/)
      
   Если найдена → ЗАГРУЖАЕТ ✅
   Если НЕ найдена → переходит к 3️⃣

3️⃣ ТРЕТИЙ ПРИОРИТЕТ:
   └─ ./photo6.jpeg
      (Резервное фото)
      
   Если найдена → ЗАГРУЖАЕТ ✅
   Если НЕ найдена → РАМКА ПУСТАЯ с эмодзи 👰
```

**ПРИМЕР:**

```
Случай А: Вы загрузили фото в браузер
   → Используется ВАШ загруженный файл ✅
   
Случай Б: Вы не загружали, но bg_image.jpeg есть
   → Используется bg_image.jpeg ✅
   
Случай В: Вы не загружали, bg_image.jpeg нет, но photo6.jpeg есть
   → Используется photo6.jpeg ✅
   
Случай Г: Нет ничего
   → Пустая рамка с эмодзи 👰
```

### ВЫЧИСЛЕНИЯ CSS:

```css
.photo-frame {
    width: 100%;              /* Полная ширина */
    max-width: 380px;         /* Максимум 380px */
    aspect-ratio: 3/4;        /* Соотношение 3:4 */
}

.photo-frame::before {
    border: 18px solid;       /* Золотая граница 18px */
}

.photo-frame img {
    inset: 18px;              /* Отступ 18px со всех сторон */
    width: calc(100% - 36px); /* 100% минус 18px*2 */
    height: calc(100% - 36px);/* 100% минус 18px*2 */
}

/* РЕЗУЛЬТАТ:
   Фото размещается ВНУТРИ рамки
   С красивым отступом
   На расстоянии от золотой границы
*/
```

## ✨ ЭФФЕКТЫ И АНИМАЦИЯ

### ЭФФЕКТ МЕРЦАНИЯ ЗОЛОТА (glowPulse):

```
Анимация работает так:

Шаг 1: Box-shadow маленький
   ↓
Шаг 2: Box-shadow увеличивается
   ↓
Шаг 3: Box-shadow становится максимальный (золотой свет)
   ↓
Шаг 4: Box-shadow уменьшается
   ↓
Шаг 5: Вернулось в начало
   ↓
ПОВТОРЯЕТСЯ БЕСКОНЕЧНО

Длительность: 5 секунд (5s ease-in-out infinite)

ВИЗУАЛЬНО:
┌──────────────┐
│ слабое свечение
└──────────────┘
        ↓
┌──────────────┐
│ ярко светится!
└──────────────┘
        ↓
┌──────────────┐
│ слабое свечение
└──────────────┘
```

### ЭФФЕКТ ПОЯВЛЕНИЯ (scaleIn):

```
При загрузке страницы:

Шаг 1: Рамка масштаб 90% (маленькая), прозрачная
   scale(0.9), opacity(0)
        ↓
Шаг 2: Рамка увеличивается, проявляется
   → scale(1), opacity(1)
        ↓
Шаг 3: Анимация завершена, рамка видна ✅

Длительность: 1 секунда
Задержка: 0.6 секунды (600ms)

ЭФФЕКТ:
• Сначала она скрыта
• Потом плавно появляется и увеличивается
• Красивый эффект входа
```
